# Micro Projects:

Smaller isolated projects in Java. <br>

## Currently includes:

### RSA encryption/decryption suite
* 1024-bit Encryption keys <br>
* Keys read/write .txt file support <br>
* Supports arbitrarily big file sizes and formats <br>
* No support for Tamper-proofing using SHA hashes <br>
* Missing non-deterministic outputs using random data injection <br>
* More efficient and faster byte-stream processing can be implemented <br>
